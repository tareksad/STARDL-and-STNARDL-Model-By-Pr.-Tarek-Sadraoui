# STARDL-and-STNARDL-Model-By-Pr.-Tarek-Sadraoui
Why These Packages? The STADRDL (Spatio-Temporal Autoregressive Distributed Lag) and STNARDL (Spatio-Temporal Nonlinear ARDL) models extend the classical ARDL/NARDL frameworks to panel data settings with spatial dependencies.  STADRDL allows spatial and temporal coefficients to differ jointly across spatial units.
